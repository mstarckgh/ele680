# ELE680 – 24 h-ahead electricity load forecasting: LSTM/GRU vs TCN

Replication of the sequential-vs-convolutional comparison of Bai et al. (2018) and Lai et al. (2018)
on UCI ElectricityLoadDiagrams20112014 (10 clients, hourly mean, one-shot 24 h forecast).

## Setup
```bash
uv venv --python 3.12 && source .venv/bin/activate
uv pip install torch numpy pandas matplotlib pyyaml pyarrow pytest
./scripts/download_data.sh          # -> data/raw/LD2011_2014.txt
pytest tests                        # causality + receptive-field checks
```
Clients are chosen once (seeded, no zero-load hours since 2012) and stored in `configs/clients.json`.
Chronological split 70/10/20 from 2012-01-01; z-scoring uses train statistics only.

## Experiments
`configs/*.yaml` (generated by `scripts/make_configs.py`), 5 seeds each:

| prefix | what |
|---|---|
| `main_{lstm,gru,tcn}` | L=168, parameter-matched (~65–70k params) |
| `len_<model>_L<L>` | input-length sweep L ∈ {24, 72, 336, 672} |
| `rf_tcn_n<n>` | TCN depth/receptive-field ablation at L=672 (n=7 is `len_tcn_L672`) |

Single run: `python -m src.train --config configs/main_tcn.yaml --seeds 5` → `results/main_tcn.json`.

Slurm (one array task per config, 20 tasks):
```bash
python -m src.run_baselines                         # seasonal-naive baselines, cheap
sbatch --array=0-19 scripts/slurm_array.sbatch      # adjust partition/GRES in the script
```
Sequential alternative: `scripts/run_all.sh`.

## Analysis
`python -m src.plots` prints the results table and writes `figures/input_length.pdf`, `figures/horizon_mae.pdf`.

## Layout
`src/data.py` pipeline · `src/models.py` LSTM/GRU/TCN · `src/train.py` training/eval · `src/metrics.py` MAE/RMSE/RSE/CORR · `src/baselines.py` · `tests/`

## References
Bai, Kolter & Koltun (2018), *An Empirical Evaluation of Generic Convolutional and Recurrent Networks for Sequence Modeling*.
Lai et al. (2018), *Modeling Long- and Short-Term Temporal Patterns with Deep Neural Networks*, SIGIR.
The TCN is written from scratch following the architecture in Bai et al.; no external code is used.
